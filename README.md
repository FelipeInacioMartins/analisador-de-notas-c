# Analisador de Notas em C

## Sobre o projeto

Este projeto consiste em um programa desenvolvido em linguagem C para analisar as notas de um aluno, calcular sua média e apresentar informações sobre seu desempenho acadêmico.

O objetivo foi praticar e estudar conceitos fundamentais de programação, como estruturas condicionais, estruturas de repetição, vetores e algoritmos de ordenação.

## Funcionalidades

- Leitura e validação da quantidade de notas.
- Validação das notas informadas, aceitando valores entre 0 e 10.
- Cálculo da média aritmética.
- Verificação da aprovação ou reprovação do aluno.
- Identificação da maior e da menor nota.
- Contagem das notas acima, abaixo e iguais à média.
- Ordenação das notas em ordem crescente.
- Tratamento de entradas inválidas.

## Tecnologias e conceitos utilizados

- Linguagem C
- Variáveis e operadores
- Estruturas condicionais (`if` e `else`)
- Estruturas de repetição (`while` e `for`)
- Vetores
- Validação de entradas
- Algoritmo Bubble Sort

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `main.c` em uma IDE compatível com a linguagem C, como o Dev-C++.
3. Compile e execute o programa.

## Aprendizados

O desenvolvimento deste projeto contribuiu para a prática de lógica de programação, manipulação de vetores, validação de dados e ordenação de valores.
